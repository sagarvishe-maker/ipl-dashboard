# IPL Dashboard 2008-2025

## Project Overview
Interactive IPL Data Analysis Dashboard using Python, Streamlit, Pandas and Plotly.

## Features
- IPL analysis from 2008 to 2025
- Team performance analysis
- Orange Cap
- Purple Cap
- Winner analysis
- Season wise statistics
- Interactive charts

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

## Run Project

pip install -r requirements.txt

streamlit run ipl25.py
